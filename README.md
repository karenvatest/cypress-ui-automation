# 🧪 Cypress UI Automation

A collection of practical **UI Automation exercises using Cypress and JavaScript**, focused on automating common web application elements and user interactions.

This project is part of my learning path from **Manual QA → QA Automation**.

---

## 🎯 Objectives

- 🧪 Automate web application test scenarios.
- 🔍 Practice locating and interacting with UI elements.
- 🖱️ Automate common user interactions.
- ✅ Implement assertions.
- ❌ Validate positive and negative scenarios.
- 🧠 Understand the structure of automated tests.
- 🚀 Build a strong foundation in Cypress.

---

## 📚 Exercises

### 🔐 Login

**File:** `login.cy.js`

**Objective:** Automate the login flow and validate different scenarios, including valid and invalid credentials.

**Practiced:**

- `cy.visit()`
- Element location
- `.type()`
- `.click()`
- Message validation
- Assertions
- Positive and negative scenarios

---

### 📝 Forms

**File:** `forms.cy.js`

**Objective:** Automate web forms and validate the behavior of different fields and controls.

**Practiced:**

- Text inputs
- Checkboxes
- Radio buttons
- Select fields
- Data entry
- Clearing fields
- Value validation

---

### 🔘 Buttons

**File:** `buttons.cy.js`

**Objective:** Automate button interactions and validate that the expected behavior occurs after clicking.

**Practiced:**

- Button locators
- `.click()`
- State validation
- Message validation
- Assertions

---

### 🔽 Dropdowns

**File:** `dropdowns.cy.js`

**Objective:** Automate dropdown menus and validate that the selected options are correct.

**Practiced:**

- Dropdown locators
- `.select()`
- Option selection
- Value validation
- Assertions

---

### 📊 Tables

**File:** `tables.cy.js`

**Objective:** Interact with HTML tables and validate information displayed across rows and columns.

**Practiced:**

- Table locators
- Rows and columns
- `.find()`
- `.contains()`
- Data validation
- Assertions

---

### ⚠️ Alerts

**File:** `alerts.cy.js`

**Objective:** Automate different types of alerts and validate the expected behavior after user interactions.

**Practiced:**

- Alerts
- Confirmation dialogs
- Event handling
- Message validation
- Assertions

---

### 🧩 Mini Project
**Objective:** Integrate the Cypress concepts practiced throughout the exercises into a complete UI automation flow.

**File:** `mini-project.cy.js`

**Practiced concepts:**
- Test scenario design
- UI navigation
- Locators
- User interactions
- Assertions
- Positive and negative scenarios
- Test organization
- End-to-end validation

**Goal:** Apply the previous exercises in a more realistic automation scenario, validating a complete user flow from start to finish.
